# 🚀 Reto de 0 a 5 Millones — Skills oficiales

Tu mentor de IA para montar y operar una tienda de dropshipping contra
entrega en LATAM, paso a paso: Dropi + Oktopus + Meta Ads, guiado como si
Esteban estuviera sentado al lado tuyo.

## Instalación (2 minutos)

**1.** Instala Claude Code en tu computador → [claude.com/code](https://claude.com/code)

**2.** Abre Claude Code y escribe estos dos comandos, uno después del otro:

```
/plugin marketplace add hydrop-inc/reto-skills
```

```
/plugin install reto@hydrop-reto
```

**3.** Reinicia Claude Code. Listo.

## Lo que necesitas ANTES de empezar

| # | Qué | Dónde |
|---|---|---|
| 1 | Cuenta de **Dropi** con el link de la comunidad | dropi.oktopus.lat |
| 2 | Cuenta de **Oktopus** con tu tienda creada en TU país | oktopus.lat |
| 3 | Dropi **conectado** a tu tienda de Oktopus | Oktopus → Configuración |
| 4 | **MCP de Oktopus** conectado a Claude | No te estreses: `/reto-0-requisitos` te lo conecta — solo necesitas tu API key de Oktopus (Configuración → Plataforma de agentes → API keys). Guía completa: [oktopus.lat/docs/quickstart](https://oktopus.lat/docs/quickstart) |
| 5 | **Conector oficial de Meta Ads** conectado | claude.ai → Ajustes → Conectores → "Meta Ads" (con TU Facebook) |
| 6 | En tu Facebook: página, Instagram conectado, Business Manager, **pixel creado** y **cuenta publicitaria con método de pago** | business.facebook.com |

No te preocupes si te falta algo: el primer comando lo revisa TODO por ti y
te dice exactamente qué falta y cómo resolverlo.

## Cómo se usa

Abre Claude Code y escribe:

```
/reto-0-requisitos
```

El mentor te lleva de la mano. El orden es siempre:

```
/reto-0-requisitos → /reto-1-producto → /reto-2-creativos → /reto-3-campana
```

Y con tu campaña activa, **todos los días**: `/reto-4-optimizacion`

¿Cerraste la ventana y no sabes dónde ibas? → `/reto-diagnostico`

## Actualizaciones

Cuando mejoremos las skills, actualiza con:

```
/plugin update reto@hydrop-reto
```

(y reinicia Claude Code para aplicar).

## Las 3 reglas de la casa

1. **La IA nunca prende tus campañas.** Todo se crea PAUSADO y tú lo activas
   con tu mano. Tu plata la controlas tú.
2. **Nada se publica en la primera pasada.** Revisa con carácter lo que la
   IA te entregue y pídele cambios. Hay dos tipos de personas: las que hacen
   lo que la IA dice, y las que le dicen a la IA qué hacer.
3. **El ROAS de Meta no es tu plata.** En contra entrega solo cobras lo que
   se entrega.

## ¿Algo de Oktopus falla?

Díselo a Claude tal cual ("no me carga la landing", "me da error al
importar") — las skills usan el canal oficial de soporte de Oktopus y te
traen la respuesta en la misma conversación. Documentación completa:
[oktopus.lat/docs](https://oktopus.lat/docs)
